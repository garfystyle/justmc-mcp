# JustMC на Xero

Xero компилируется в код мира JustMC Creative+. **Пиши сразу по этой странице**: `check` поймает остальное. Целые темы не читай. Нужно имя: `find`. Нужен приём: `ask`. Нужен раздел: `guide(topic, section)`, список разделов даёт `guide(topic)`. Или Grep по `references/`.

## Обязательно

- **Сервер общий.** Не доводи мир до отказа ради замера, не гоняй перезапуски подряд, держи `value.cpu_usage` ниже 50. Жалоба в чате или строка `☠` значат стоп и сообщение пользователю. С админами от его имени не говори.
- **Начни с `world` действие `status`.** `warnings` про старый код MCP: попроси перезапустить Claude Code, `/clear` не поможет. Нет файла мира: `world` действие `adopt`, без `path` только если мир пуст, иначе заливка сотрёт код. `lastStop` или `phase` строительства: код сейчас не идёт.
- **Чужой код цел.** `test` и `deploy` меняют только свой `project`. `drop` и `mode=world` только по прямой просьбе. В живой мир сначала `deploy` с `dry`. Правки руками в `/dev` файл мира не видит и заливка их сотрёт: спроси, если они могли быть.
- **Клиент общий с человеком.** Настройки и язык не меняй. После разрыва связи не переподключайся. В `/dev` не кликай по блокам и табличкам: строка сотрётся. `test` перезапускает мир: если в нём люди, спроси.
- **Отступаешь от задания: скажи словами до начала работы.**

## Цикл

1. Что должно случиться в игре и каким шагом это доказать.
2. Пиши файлы `.xero` через Write и Edit, не оболочкой. Проект больше 400 строк: папка файлов. Отладка в `*.debug.xero`: их заливает `test`, а `deploy` нет.
3. `check` до чистого результата, вместе с разделом «Читаемость».
4. `test` со сценарием, который упадёт, если поведения нет. Вызовы инструментов идут по очереди: что надо поймать во время сценария, делай шагом `shot`, `limits`, `track`.
5. Сдача: один полный сценарий на последнем коде, без отладки и бессмертия, по пути игрока. В ответе перечисли только то, что он доказал.

## Язык

```kotlin
const PREFIX = "&6[Игра] &f"
const SWORD = item(diamond_sword, name: "&bМеч", lore: ["строка"], tags: {kind: "hero"})

save `монеты %player%`
game round
game spawn_points: list

func reward(amount: number = 10) {
    `монеты %player%` += amount
    send_message("${PREFIX}Монет: ${`монеты %player%`}")
    return amount * 2
}

process tick() {
    forever {
        wait(1s)
        round += 1
    }
}

when world_start {
    spawn_points = [loc(0, 64, 0), loc(10, 64, 0)]
    start tick(target_mode: no_target)
}

when player_join {
    give_items(SWORD)
    bonus = reward(5)
    @all send_title("&a%player%", "бонус ${bonus}")
}

when player_chat {
    if chat_message_equals("@top") {
        cancel_event()
        for spot in spawn_points {
            player.teleport(spot, keep_rotation: false)
        }
    }
}
```

- **Файл:** снаружи только `const`, `import "a.xero"`, `game x`, `save x: вид`. Код живёт в `when событие`, `func`, `process`. Виды: `number text location vector item block sound particle potion list map`.
- **Переменные:** `x = 1` живёт одно срабатывание, `line x` в своём обработчике, `game x` до перезапуска, `save x` всегда. Слово области пишут один раз. `line items: list = [1, 2]`. Данные игрока: `` game `hp %player%` ``.
- **Команды:** `x += 1`, `l[0] = 5`, `m["k"] = 1`, `a, b = 1, 2`, `if … { } else if … { } else { }`, `repeat 5 { }`, `for i in 1..5 { }`, `for v in l { }`, `for i, v in l { }`, `for k: v in m { }`, `while x < 5 { }`, `forever { wait(1) }`, `break`, `continue`, `return x`, `end_thread()`.
- **Выражения:** `+ - * / %`, `== != < <= > >=`, `and or not`, `x in [1, 2]`, `c ? a : b`, `l[i]`, `len(l)`. Формула собирается в один блок: `sqrt(a * a + b * b)`. Нет `++`, `**`, `&&`, `||`, `null`, склейки строк `+`.
- **Значения:** `"&aтекст ${x + 1} %player%"`, `mm"<red>x"`, `5s 500ms 20t` (голое число в `wait` это тики), `loc(x, y, z, yaw, pitch)`, `vec(x, y, z)`, `item(id, 3)`, `block(id)`, `sound(id)`, `particle(id, count: 5)`, `potion(id)`, `[a, 2]`, `{"k": a}`, `value.location`.
- **Цели перед вызовом:** `@all`, `@default`, `@killer`, `@victim`, `@current`, `@last`: `@last set_display_scale(vec(2, 2, 2))`, `x = @victim value.current_health`, `"${@killer value.name}"`.
- **Условия:** `if is_sneaking() and not has_item(item(stone)) { }`. Выборка: `entity_by_name("x")`, затем `@current …`, затем `reset()`.
- **Действия с результатом:** `y = shift_coordinate(l, 5, type: y)`. Имена из нескольких категорий с приставкой: `player.teleport`, `entity.remove`. Имя с пробелом или плейсхолдером в обратных кавычках.

## Ловушки

- В событии мира игрока нет: `@all`. Цикл без `wait` сервер оборвёт. Локальные у функции и вызвавшего общие.
- Незаданная переменная обнуляет формулу: счётчик пиши `x += 1`.
- Вектор в формуле сервер молча считает нулём. Список из векторов в своём коде компилятор узнаёт сам, чужой клади в `game v: vector`.
- Параметр в имени и тексте только `%var_line(p)`, `%var_local(p)` его не видит. Атрибуты с приставкой `generic_`.
- `loc()` зажимается границей карты молча. `exception(err)` без ошибки даёт 0. Бюджет тика 4 мс: считай `measure_time`, а не оценками.
- Событие, которое обрабатываешь сам, отменяй первой строкой. Свои предметы и сущности различай тегом, а не именем. Тяжёлое не в `player_move`, большую работу порциями с `wait`.
- Модули из `examples` писали разные люди: бери приём, а не код.

## Читаемость

Имена словами: `boss_health`, не `b_hp`. Состояния константами: `boss_mode == MODE_FIGHT`. Функция до 40 строк. Числа баланса и теги в `const`, повтор кода в `func`, условие отказа сверху с `return`. Комментарий не лечит плохое имя. Подробно: `style`.

## Визуализаторы

- Настраивай через `@last`, без цели действие уйдёт игроку и ничего не сделает.
- Они переживают перезапуск: метка `set_custom_tag` и чистка в `world_start` обязательны.
- Плавно: `set_display_interpolation(20, 0)` перед изменением, только частям, которые меняются. Сразу после спавна нужен `wait(1)`.
- `entity.teleport` без маркера берёт поворот из точки, `keep_rotation: false` его не применяет. Мобу с ИИ поворот ставь `entity.set_rotation`.
- Смотри, а не гадай: `see` действия `displays` и `track`, `screenshot` с `orbit`. Тема `displays`.

## Сценарий test

```json
[{"say": "@shop"}, {"gui": "Магазин"}, {"click": "Купить"}, {"expect": "Куплено"},
 {"var": {"name": "монеты Steve", "scope": "save", "equals": 90}}, {"item": "emerald", "count": 2}]
```

Все глаголы в описании `test`. Читай `seen`: там здоровье, смерти, спавны и то, что ты не проверял. `attack` при промахе не падает, смотри заметку шага. `tolerate` снимает ожидаемые ошибки, но не `☠`. Предел 100 с, долгое: `script` с `background` и `wait`, бой: `fight-bot`. Убирай за собой мобов и блоки. `script` проверкой не считается, смотри `errors`.
