## Что умеет

- **Пишет код сразу правильно.** Скилл `justmc` держит весь язык Xero на одной странице, а руководство из 16 тем
  открывается по разделам, только когда нужно.
- **Знает, как пишут другие.** База собрана из 1075 открытых модулей каталога JustMC: типичные значения аргументов,
  что обычно идёт следом, готовые идиомы, связь русских слов с действиями.
- **Проверяет сам.** `check` собирает код и предлагает правки, `test` заливает его в мир, ведёт игрока по сценарию и
  возвращает короткий отчёт: чат, экшенбар, тайтлы, переменные, инвентарь, ошибки сервера.
- **Видит игру.** Сущности, визуализаторы с полным состоянием, блоки, частицы, звуки, снимки экрана с любой точки,
  замер рывков анимации по кадрам.
- **Не ломает чужое.** Заливка меняет только свой проект, перед каждым изменением мира пишется копия.

## Инструменты

| Инструмент | Что делает |
|:--|:--|
| `ask` | один вызов на задачу: разделы руководства, имена, настоящий код |
| `guide` | руководство: список тем, список разделов темы, один раздел (`section`), тема целиком (`full`) |
| `find` | карточка имени: аргументы и примеры, `full` добавит типичные значения из модулей и что обычно дальше |
| `examples` | код модулей: поиск, по приёму, по имени, модуль целиком, список модулей |
| `check` | сборка: ошибки, подсказки, правки (`fix`), стиль (`format`), раздел «Читаемость» |
| `test` | залить, зайти игроком, пройти сценарий, вернуть короткий отчёт и всё, что увидел клиент |
| `deploy` | залить без проверки, `dry` показывает изменения |
| `world` | состояние, TPS и пинг, код мира, ответы сервера, дерево команд |
| `player` | ходьба с поиском пути, взгляд, клики, чат, инвентарь, окна |
| `see` | HUD, визуализаторы, сущности и их счёт, блоки, карта области, журнал сети, замер рывков `track` |
| `screenshot` | снимок, камера из любой точки, облёт модели и серия кадров без движения игрока |
| `execute` | BeanShell в клиенте, у каждого вызова своя область, при ошибке подсказывает настоящие методы |
| `script` | свои скрипты: сохранить, запустить, дождаться (`wait`), остановить, записать игрока, повторить запись |

Промпт `code` запускает весь цикл под задачу. Без игры работают `ask`, `guide`, `find`, `examples` и `check`.

## Установка

Нужен [Node.js](https://nodejs.org) 22.13 или новее. Одна команда скачивает MCP в `~/.justmc-mcp/app`, собирает базу
знаний и подключает сервер и скилл ко всем найденным программам.

**Windows** (PowerShell):

```powershell
irm https://raw.githubusercontent.com/garfystyle/justmc-mcp/main/install.ps1 | iex
```

**macOS и Linux:**

```bash
curl -fsSL https://raw.githubusercontent.com/garfystyle/justmc-mcp/main/install.sh | sh
```

Обновить — та же команда. Поставил новую программу — запусти её ещё раз, она подключит и её. После установки
программы нужно перезапустить.

| Программа | Куда пишется сервер |
|:--|:--|
| Claude Code | `claude mcp add --scope user` |
| Claude Desktop | `claude_desktop_config.json` |
| Codex CLI | `~/.codex/config.toml`, предел вызова 15 минут |
| Gemini CLI | `~/.gemini/settings.json` |
| Antigravity | `~/.gemini/config/mcp_config.json` |
| Qwen Code | `~/.qwen/settings.json` |
| GitHub Copilot CLI и VS Code | `~/.copilot/mcp-config.json`; VS Code до 1.143 — `mcp.json` профиля |
| Cursor | `~/.cursor/mcp.json` |
| OpenCode | `~/.config/opencode/opencode.json` |
| Kilo Code CLI | `~/.config/kilo/kilo.json` |
| Crush | `~/.config/crush/crushrc` |
| Goose | `config.yaml` Goose |
| Amp | `~/.config/amp/settings.json` |
| Kiro, Amazon Q Developer CLI | `~/.kiro/settings/mcp.json`, `~/.aws/amazonq/mcp.json` |
| Factory Droid | `~/.factory/mcp.json` |
| Augment Auggie | `~/.augment/settings.json` |
| Cline | `~/.cline/data/settings/cline_mcp_settings.json` и расширение Cline |
| Continue | `~/.continue/config.yaml`, если он уже есть |
| Devin Desktop и Devin CLI (бывший Windsurf) | `mcp_config.json` Devin |
| Zed | `settings.json` Zed, ключ `context_servers` |
| Warp | `~/.warp/.mcp.json` |
| Rovo Dev, Kimi Code, Mistral Vibe, Qoder, Junie, Grok, Pi, Cortex Code | свой файл MCP каждой программы |

Скилл `justmc` ложится в общую папку `~/.agents/skills`, её читает большинство программ. Отдельные копии — для
Claude Code (`~/.claude/skills`), Antigravity, Kiro, Copilot в VS Code, Cline и Pi.

Чужие серверы, комментарии и отступы в конфигах остаются как были, файл с ошибкой разбора не трогается. Копия каждого
файла перед правкой лежит в `~/.justmc-mcp/config-backups`.

| Команда | Что делает |
|:--|:--|
| `node ~/.justmc-mcp/app/scripts/setup.mjs --dry` | показать, что изменится, ничего не записывая |
| `node ~/.justmc-mcp/app/scripts/setup.mjs --only=codex,cursor` | подключить только эти программы |
| `node ~/.justmc-mcp/app/scripts/setup.mjs --modules` | докачать модули JustMC для `examples`, около 50 минут |
| `node ~/.justmc-mcp/app/scripts/setup.mjs --remove` | убрать сервер и скилл отовсюду |

Без модулей работает всё, кроме `examples` и значений из чужого кода в `find full`: справочник и руководство уже в
базе. На Windows те же команды работают с путём `%USERPROFILE%\.justmc-mcp\app\scripts\setup.mjs`.

**Если вызов обрывается.** `test` идёт до нескольких минут, поэтому установщик поднимает предел времени там, где он
настраивается. Cursor CLI и Continue обрывают любой вызов через 60 секунд, Claude Desktop — тоже рано: там
`test` подолгу не дождаться. Gemini CLI не запускает MCP-серверы в папке, которой не доверяет.

Из исходников: `git clone`, затем `npm install` и `npm run setup` в папке проекта.

## Проверка в игре

Для `test`, `deploy`, `player`, `see`, `screenshot`, `execute` и `script` нужен Minecraft 26.2 и два мода:

- [XeroCode](https://github.com/garfystyle/xerocode): заливает код в мир и связывает игру с MCP;
- mcexec: мост, через который в живой клиент загружается агент. Он пока не выложен.

Агент написан на Java и подгружается в клиент на лету, без перезапуска игры. Он держит свой порт, поэтому переживает
зависшие вызовы, видит сеть клиента и ведёт игрока по тикам. Всё, что он делает в тике, изолировано: ошибка пишется в
`lastError`, а 40 ошибок подряд отключают агента, не трогая игру.

Ответы сервера узнаются на русском, английском и украинском по строкам локализации JustMC, поэтому язык клиента менять
не нужно.

## Безопасность мира

- `test` и `deploy` заменяют только прошлую заливку этого проекта (`project`), остальной код мира остаётся. Что
  сотрётся, видно в поле `attention`. Одноимённые чужие `func` и `process` заливка заменять отказывается без `drop`.
- `deploy` с `mode=world` заменяет весь код и откажет без `drop`, если что-то сотрётся.
- Перед изменением копия мира пишется в `~/.justmc-mcp/backups`. Вернуть: `deploy` с `path` на этот файл и
  `mode=world`.
- В `/dev` ЛКМ и ПКМ игрока запрещены без `force`: удар по блоку-событию стирает строку.

Код мира из игры не читается, он лежит в `~/.justmc-mcp/worlds/<мир>.json`: его пишет каждая успешная заливка, и от
него считаются `deploy`, `test` и `world read`. Файла нет: `world` с действием `adopt`. Правки руками в `/dev` этот
файл не видит, после них — `deploy` с `resend`.

## Как устроено

| Часть | Что делает |
|:--|:--|
| `src/knowledge` | база из модулей: значения аргументов, что идёт за чем, идиомы, связь слов и действий, теги приёмов, поиск по руководству |
| `src/xero` | ядро Xero: сборка, формат, чтение кода мира, сверка, проверка читаемости |
| `src/game` | заливка, сценарии проверки, управление игроком, скрипты |
| `agent/` | агент на Java для живого клиента, собранный лежит в `vendor/agent.jar` |
| `knowledge/guide` | руководство по темам |
| `skill/` | скилл `justmc`: язык и правила работы |
| `mc-scripts/` | библиотека скриптов: BeanShell, сценарии на JS, записи игрока |

**Знания стоят контекста.** Веса модели не меняются, поэтому всё, что агент знает о Xero, он читает по ходу работы.
`SKILL.md` короткий и держит весь язык: важное стоит в начале, потому что после сжатия разговора от скилла остаются
первые 5000 токенов. Темы руководства ничего не стоят, пока их не открыли, и читаются разделами. Остальное ловит цикл:
`check` даёт ошибку с подсказкой, `find` даёт точное имя. Поэтому в скилл попадает только то, без чего агент ошибётся
молча.

**Читаемый код.** `check` проверяет не только сборку: непонятные имена, числа вместо именованных состояний, повторы,
длинные обработчики, глубокую вложенность, счётчики вместо `for`. Правила и примеры лежат в теме `style`. Комментарии
не требуются: код объясняет себя именами. Файлы `*.debug.xero` заливает только `test`, поэтому тестовые команды не
попадают в итоговый код.

**Старый процесс.** Сервер MCP живёт, пока запущен Claude Code, а руководство и скилл читаются с диска. После обновления
нужен перезапуск Claude Code: `world status`, `test` и `deploy` предупреждают, если код новее процесса или скилл старее
руководства.

## Данные

| Команда | Что делает |
|:--|:--|
| `npm run crawl` | докачивает модули каталога, по лимиту сервера, с места остановки |
| `npm run learn` | учится на модулях и собирает базу `data/knowledge.db` |
| `npm run setup` | подключить сервер и скилл ко всем найденным программам |
| `npm run skill` | обновить только скилл Claude Code |
| `npm run sync` | для разработки: берёт ядро Xero и справочник из соседней папки `justmc/xero` |
| `npm run agent` | собирает агента в `vendor/agent.jar` |
| `node scripts/cli.mjs <инструмент> '<json>'` | вызвать инструмент из терминала |

Скачиваются только открытые и бесплатные модули. Их код лежит локально в `data/` и в репозиторий не входит: у него
есть авторы.
